## Что сделано
Добавлена возможность устанавливать приоритет задачи (низкий / средний / высокий).
- В модель `Task` добавлено поле `priority` (enum: `LOW`, `MEDIUM`, `HIGH`, по умолчанию `MEDIUM`)
- Миграция Prisma создана и применена
- Backend: новые поля в `CreateTaskDto` / `UpdateTaskDto`, валидация через `class-validator`
- Frontend: выпадающий список приоритета в форме создания/редактирования задачи, цветовые метки на карточке задачи

## Причина изменений
Пользователи не могут различить срочные и второстепенные задачи. Приоритет позволяет визуально выделить важное и в будущем добавить сортировку по нему.

## Как тестировать
1. Запустить приложение: `npm run dev`
2. Создать новую задачу — убедиться, что выпадающий список «Приоритет» присутствует (значение по умолчанию — «Средний»)
3. Выбрать «Высокий» — карточка должна получить красную метку
4. Выбрать «Низкий» — карточка должна получить серую метку
5. Отредактировать существующую задачу — приоритет должен сохраняться и обновляться корректно
6. Проверить, что у старых задач (без явного приоритета) отображается «Средний»
